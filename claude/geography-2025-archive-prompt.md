# პრომპტი: გეოგრაფიის 2025 წლის საარქივო იმიტირებული გამოცდა

დაწერილია იმავე არქიტექტურის მიხედვით, რაც უკვე აშენდა ისტორიისთვის (`historyExamsData.ts`, `HistoryExamSimulation.tsx`, `history-open-answer-grader-schema.ts`) და მათემატიკისთვის (`mathExamsData.ts`, `MathExamSimulation.tsx`, `math-open-problem-grader-schema.ts`). წაიკითხეთ ეს ორი რეალიზაცია საწყის წერტილად — გეოგრაფიის არქიტექტურა **ყველაზე ახლოს დგას ისტორიასთან** (თითოეული ღია ქვეპუნქტი = კონკრეტული პასუხი + წყაროზე დაფუძნებული დასაბუთება, ორივე ცალ-ცალკე ფასდება).

## 0. წყარო მასალები

საწყისი PDF-ები უკვე გადატანილია რეპოში (`docs/exam-sources/geography/`):

| `docs/exam-sources/geography/scoring-variant-1-2025.pdf` | ოფიციალური შეფასების სქემა, 6 გვერდი |

⚠️ **მხოლოდ 1 ვარიანტია** მოწოდებული — მონაცემთა მოდელი უნდა აშენდეს **გაფართოებადი** სახით (მასივი ვარიანტებისთვის), მაგრამ ამჟამად მხოლოდ ერთი ვარიანტი უნდა შეივსოს (`variant: 1`).

## 1. დადასტურებული გამოცდის სტრუქტურა

- **მაქსიმალური ქულა:** 59. **ხანგრძლივობა:** 2 საათი 40 წუთი (9600 წმ).
- **ნაწილი 1 — ტესტური კითხვები (1–27, თითო 1 ქულა = 27 ქულა).** ოთხპასუხიანი არჩევითი (ა/ბ/გ/დ). **უკიდურესად სურათებზე/რუკებზე/დიაგრამებზე დამოკიდებული** — თითქმის ყოველ კითხვას სჭირდება ვიზუალი. იშვიათ შემთხვევებში თავად **პასუხის ვარიანტებია სურათები** (მაგ. კითხვა 14).
- **ნაწილი 2 — ღია დავალებები (28–37, ჯამში 32 ქულა):**
  - **28** (28.1–28.3, თითო 1 ქ.) — მოკლე დასაბუთებული პასუხი წყაროზე დაყრდნობით.
  - **29** (1 ქ.) — გამოთვლითი ღია პასუხი. **30** (1 ქ.) — ღია პასუხი (თარიღი/წელი).
  - **31.1, 31.2** (თითო 1 ქ.). **32** (2 ქ.: პასუხი 1 + დასაბუთებული მიზეზი 1).
  - **33.1, 33.2** (თითო 1 ქ.). **34.1** (2 ქ.: კონტინენტი 1 + % გამოთვლა 1), **34.2** (1 ქ.).
  - **35.1** (1 ქ.), **35.2** (1 ქ.), **35.3** (2 ქ.: ტერმინი 1 + დასაბუთება 1).
  - **36.1–36.4** (თითო 2 ქ. = 8 ქ.) — **ისტორიის 36.1–36.6-ის ზუსტი ანალოგი**: კონკრეტული პასუხი (1 ქ.) + წყაროზე (რუკა/ფოტო/დიაგრამა) დაფუძნებული დასაბუთება (1 ქ.). **თუ დასაბუთება არ ეხმიანება წყაროს, 0 ქულა პასუხის ნაწილშიც.**
  - **37.1, 37.2** (თითო 1 ქ., ტესტური), **37.3** (1 ქ., გამოთვლა), **37.4** (1 ქ., დასაბუთება), **37.5** (2 ქ.: ორი დამოუკიდებელი დასაბუთებული პასუხი).
  - **ჯამი:** 27 + 3+1+1+2+2+2+2+1+2+2+8+4+2 = **59** ✓

## 2. მონაცემთა მოდელი — `src/data/geographyExamsData.ts`

`historyExamsData.ts`-ის ანალოგიით, ფიგურების მხარდაჭერით MCQ-ს, პასუხის ვარიანტების და ღია დავალებების დონეზეც. ძირითადი ტიპები: `GeographyFigure { src, alt, caption? }`, `GeographyOption { label, text?, figure? }`, `GeographyMcqQuestion { id, number, prompt, figures?, options, correctLabel, points: 1 }`, `GeographyOpenSubItem { id, number, prompt?, figures?, maxPoints, answerCriteria: { id, description, points, requiresSourceReference? }[], modelAnswerNote? }`, `GeographyOpenTask { id, number, instructions?, subItems }`, `GeographyExamVariant { variant, mcq, openTasks, maxPoints: 59, durationSeconds: 9600 }`, `GeographyExamYear`. მონაცემები ცალკე ფაილში `src/data/geographyExams2025.ts`.

- ამოიღეთ **ყველა** სურათი/რუკა/დიაგრამა ვიზუალურად დამოკიდებული MCQ-დან (თითქმის ყველა 1–27) და ღია დავალებებში ნახსენები წყაროებიდან (28, 32, 33, 35.3, 36.1–36.4…).
- შეინახეთ `public/exam-figures/geography/variant-1-2025/q<N>.png` (ან `q<N>-<sub>.png`), მაღალი გარჩევადობით.
- **არ გამოტოვოთ არცერთი** — ეს ისტორიის არქივის შეცდომაა (`history-missing-map-figures-prompt.md`), აქ მასშტაბით უფრო დიდი.

## 4. AI-შეფასების არქიტექტურა — `src/lib/ai/geography-open-task-grader-schema.ts`

მოდელირებულია `history-open-answer-grader-schema.ts`-ზე (არა writing-grader-ზე). AI აფასებს, თითოეული `answerCriteria` შესრულდა თუ არა; `requiresSourceReference: true`-სთვის სპეციალურად ამოწმებს, ახსენებს თუ არა მოსწავლე მითითებულ წყაროს. ქულა **სერვერზე** გამოითვლება კრიტერიუმების ჯამიდან (`scoreFromSteps` პატერნი, არასდროს AI-ს თვითდეკლარირებული ქულიდან). ბარე ფუნქცია `gradeGeographyOpenSubItem` + ჰუკი `useGeographyOpenGrading` (`Promise.all`-სთვის). ახალი `pageType` `page-types.ts`/`page-prompts.ts`/`route.ts`-ში. ლოკალური fallback `geography-open-task-grader-local.ts`.

## 5. გამოცდის სიმულაცია — `src/components/abiturient/exams/GeographyExamSimulation.tsx`

იგივე დეფერდ-რივილ პატერნი (`Stage = "mcq" | "open" | "done"`). MCQ-ზე `reveal={false}` მკაცრად. `დასრულება`-ზე: MCQ კლიენტზე, ღია დავალებები `Promise.all`-ში. შედეგებზე: ქულა/59, თითო სექცია აკორდეონად (რა დაწერა, რომელი კრიტერიუმი შეასრულა — განსაკუთრებით წყაროს ხსენება, მოდელური პასუხი, რატომ). MCQ სექციაც აკორდეონად.
